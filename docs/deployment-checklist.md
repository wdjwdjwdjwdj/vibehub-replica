# 起站试用版部署清单

当前部署对象是独立品牌、免登录的静态试用版。账号后端和历史复刻内容均不属于首发范围。

## 发布前

- 确认“起站”工作名、域名及长期使用条件；没有确认前可用预览域名小范围测试。
- 只发布 `npm run build` 生成的 `dist/`，不要上传整个仓库、`server/`、`public/` 或 `replication-evidence/`。
- 检查 `dist/` 只包含入口文件、构建后的 JS/CSS、`qizhan-mark.svg`、`qizhan-hero.png` 和 `_redirects`。
- 为所有路径配置 SPA 回退到 `index.html`，确保 `/guide/html`、`/practice` 和 `/favorites` 刷新不会 404。
- 开启 HTTPS，并将 HTTP 跳转到 HTTPS。
- 配置自定义域名时，同时验证根域名与 `www` 的唯一主地址。

## 发布后验收

- 首页、8个概念详情、练习和收藏页可直接打开并刷新。
- 收藏后进入“我的收藏”可以看到对应概念。
- 答对一题后刷新页面，本地进度仍存在。
- 手机宽度 390px 下没有横向滚动，导航、答题和按钮可操作。
- 浏览器控制台没有运行时错误，Network 中没有账号或后端 API 请求。
- 页面标题、favicon、Logo、描述均为独立品牌。
- 清除站点数据后收藏与进度被清空，并且页面仍可正常使用。

## 回滚

- 保留上一份可用的 `dist/` 构建产物或使用托管平台的上一版本回滚功能。
- 本版没有数据库迁移，回滚不会处理服务端数据。
- 发布出现阻断问题时先恢复上一版本，再在预览环境修复并重跑 `npm run test:e2e`。

## 本轮未包含

- 公网平台和账号操作
- 域名购买或备案
- 访问分析、错误监控和用户反馈收集
- 登录、邮件、支付、云端收藏或云端学习记录
